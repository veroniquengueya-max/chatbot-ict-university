# chatbot-ict-university
Assistant scolaire bilingue (FR/EN) : chatbot, generation de QR Codes et suivi des notes pour THE ICT University.

## Fonctionalités
- Chatbot bilingue (FR/EN)
- Generation de QR Codes (admission et paiement)
- Suivi des notes et statistiques

## Installation
pip install -r requirements.txt
streamlit run app.py
